# Contributing

AI Limit Notifier is being developed under a dual-licensing model: noncommercial public use plus separately negotiated commercial licenses.

To avoid creating unclear ownership or relicensing rights while that model is being established, **external code contributions are not accepted yet**.

You are welcome to:

- open bug reports;
- describe compatibility problems;
- suggest features;
- provide reproducible test cases;
- report documentation mistakes;
- report security issues through the security contact process once published.

Please do not submit source-code pull requests unless the repository owner explicitly invites the contribution and the required contributor-rights process is in place.

## Why code contributions are temporarily restricted

The project owner must be able to offer commercial licenses for the complete product. Accepting third-party code without an appropriate contributor agreement can make those rights unclear or impossible to grant consistently.

Before normal external code contributions are enabled, the project will choose and publish an appropriate contributor agreement/process that preserves both:

1. the contributor's rights and attribution; and
2. the project owner's ability to distribute the complete project under both the public noncommercial license and separate commercial licenses.

## Development workflow

The repository owner currently develops the product directly on `main`. `main` must remain buildable and tested. See `docs/PROJECT_STATUS.md` and `docs/RELEASE_CRITERIA.md` for the current implementation priorities and release gates.
